# Arabic SEO Toolkit

Arabic-first SEO toolkit for Salla and Zid merchants by Grovlix.

## What it includes

- Web app with Arabic/English localized pages
- SEO audit engine for titles, descriptions, headings, images, schema, internal links, RTL, and PageSpeed summary
- Meta tag generator
- Schema.org generator
- SERP preview
- CLI for audits and generation

## Local development

```bash
npm install
npm run dev
```

CLI development:

```bash
npm run cli:dev -- audit https://example.com --output json
```

## Scripts

- `npm run dev`
