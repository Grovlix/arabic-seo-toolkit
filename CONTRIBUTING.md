# Contributing

## Setup

1. Install Node.js 20 or newer.
2. Run `npm install`.
3. Start the app with `npm run dev`.

## Standards

- Keep Arabic support RTL-first.
- Prefer TypeScript for all new code.
- Do not store merchant URLs or audit payloads server-side.
- Run `npm run test` before opening a PR.

## Pull requests

- Explain the user-facing impact.
- Include screenshots for UI changes.
- Mention any SEO assumptions or external-source dependencies.
